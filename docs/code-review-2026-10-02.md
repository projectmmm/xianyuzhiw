## 清理与兼容性

- ESLint 检查代码质量，Prettier 处理布局；未通过全局关闭未使用变量、导入或其他质量规则掩盖问题。少数原生对话框与异步循环使用说明原因的局部豁免。
- `lint`、`format:check` 只读；`lint:fix`、`format` 显式修改。Node.js 24 写入 `.nvmrc`，pnpm 版本通过 packageManager 固定，显式声明 ESLint/Prettier 依赖并更新锁文件。
- Vue 登录页采用 `TokenImport`、`ManualTokenForm`、`SingleBinTokenForm` 等名称。对比生成路由，22 个名称和 URL 全部保持原值。
- 应用内部导入使用 `@/`；Node 直接运行的脚本仍使用相对路径。Vite/TypeScript 同步删除无调用别名。
- 原有宽松比较通过小型兼容方法保留，避免格式和严格比较规则改变字符串/数字 ID、null 等值的行为。外部 API、游戏命令和存储键不因清理改名。
- 未确认无用的公开导出、可通过路由访问的页面、动态加载入口、调试/手工脚本和带副作用调用保留。第三方及解读游戏源码不改写。
